# vk_automatization — автотесты REST API SWAPI

Тесты проверяют публичный
**Star Wars API** ([swapi.dev](https://swapi.dev/api)) с помощью **REST Assured**, **JUnit 5**,
**AssertJ** и **Jackson**.

## Проверяемое API

[SWAPI](https://swapi.dev/api) — публичный REST API по вселенной Star Wars. Отдаёт JSON,
работает без авторизации, поддерживает постраничную выдачу и поиск. В тестах используются:

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/people/` | список персонажей, параметры `page` и `search` |
| `GET /api/people/{id}/` | персонаж по ID |
| `GET /api/films/` | список фильмов, параметр `page` |
| `GET /api/films/{id}/` | фильм по ID |

Проверяются успешные ответы (`200`) и обработка ошибок (`404` для несуществующих или
некорректных ID/параметров).

## Что покрыто тестами

**SwapiTest** — работа с людьми (`/people/`) и фильмами (`/films/`):

- получение персонажа по ID: код 200, непустое имя, список фильмов;
- получение фильма по ID: код 200, режиссёр, формат даты релиза;
- несуществующий персонаж — код 404;
- нечисловой ID — код 404;
- пагинация первой страницы: `count`, `results`, `previous`, `next`;
- отсутствие пересечений между первой и второй страницами;
- корректные ссылки навигации на второй странице (`page=1`, `page=3`);
- поиск людей по строке (`?search=luke`).

**GetFilmTest** — негативные сценарии `GET /films/{id}/`:

- нецелочисленный ID (`1.5`) — код 404;
- ID ниже минимальной границы (`0`) — код 404.

**ListFilmsTest** — негативные сценарии `GET /films/`:

- нецелочисленный параметр `page` (`1.5`) — код 404;
- значение `page` ниже минимальной границы (`0`) — код 404.

## Как используется `openapi.yaml`

`src/test/resources/openapi.yaml` — контрактное описание SWAPI (OpenAPI 3.1) для эндпоинтов
`GET /films/` (`listFilms`) и `GET /films/{id}/` (`getFilm`): параметры, схемы ответов и коды
ошибок (включая 404).

Спецификация лежит в тестовых ресурсах по ней:
- сгенерированы тесты в пакете `generated` (`GetFilmTest`, `ListFilmsTest`).
- сверяются ожидаемые коды ответов и граничные значения параметров (`id`, `page`).
- Во время выполнения тестов файл не парсится и не используется как runtime-конфигурация —
  это документация и основа для генерации/актуализации тестов.

## Требования

- **JDK 25** (в `pom.xml` задано `maven.compiler.release=25`)
- **Maven 3.8+**
- Доступ в интернет к `https://swapi.dev/api`

## Сборка проекта

```bash
# полная сборка с прогоном тестов
mvn clean package

# только компиляция (main + test)
mvn clean test-compile
```

Готовый артефакт: `target/vk_automatization-1.0-SNAPSHOT.jar`.

## Запуск тестов

```bash
# все тесты
mvn test

# только основные REST-тесты
mvn test -Dtest=SwapiTest

# негативные тесты по фильмам
mvn test -Dtest=GetFilmTest,ListFilmsTest
```
Результаты прогона сохраняются в `target/surefire-reports/`.
